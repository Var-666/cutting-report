# 当前系统架构

> 更新日期：2026-09-21。本文档记录当前实现，详细需求与 V1 设计仍以 `docs/design/` 为准。

## 总体结构

```text
Vue 3 页面
  ↓ 同源 HTTP API
FastAPI 路由与权限边界
  ↓
业务 Service
  ├─ 报表查询、统计、智能分析、HTML/PDF
  ├─ 工人确认、文件派发、邮件自动化
  └─ 告警监控与报告
  ↓
Repository / 外部系统客户端
  ├─ SQLite：应用元数据、快照、任务和审计记录
  ├─ SQL Server / Excel：生产报表源
  ├─ HR / PDM：人员与切割文件源
  └─ 能管、激光魔盒、SMTP、LLM：外部服务
```

生产式部署由 FastAPI 同源提供前端静态资源和 API。报表、告警、历史缓存、临时文件清理和统一数据保留使用应用内后台线程，因此当前维持单 Uvicorn worker。

## 主要模块关系

- 三类标准报表共用查询区间、中文日期显示、表格列宽规则和智能分析面板。页面、导出和分析必须保持同一数据口径。
- 智能分析由报表 API 提供 `analysis_source_version`，服务端根据规范化业务数据计算 `data_version`，再查询 SQLite 缓存。
- 车间任务确认以 `TASK_ID` 为唯一任务键，确认、撤销和管理更正在 SQLite 留存审计记录，不写回生产库。
- 文件派发对用户是一体化流程：直接从 PDM 选择文件并创建任务，执行时复核版本和路径，再通过 FO 临时下载、校验、上传魔盒并指派机床。内部阶段和审计记录保持独立，推送成功后删除临时实体副本。
- 报表自动化由计划、报表生成、邮件队列和失败重试组成。运行与 SMTP 参数由管理页写入 `data/settings.env`，并向单进程 worker、自动化和邮件服务发布同一配置快照；新操作即时生效，数据库配置仍需重启。
- 统一保留任务每天清理已终结的报告、分析版本、告警、派发和审计数据；文件删除通过 SQLite 重试队列执行，活动记录和待发送邮件不进入清理范围。

## 不可破坏的边界

- 业务逻辑放在 service，数据库细节放在 repository，API 层不重复实现业务规则。
- 管理员/工人的前端路由和后端授权必须同步。
- 外部数据库和平台默认只读；应用仅修改自有 SQLite 和受控运行文件。
- 密码、Token、Cookie 和 LLM/API 密钥不返回浏览器、不进入报表或普通日志。
