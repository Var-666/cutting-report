# 项目进度

> 更新日期：2026-09-21。

## 当前状态

系统已进入持续完善和内网联调阶段。标准报表、区间查询/导出、智能分析、工人确认、切割文件派发、告警报告和报表自动化均已有可运行实现。当前分支后端 444 项、前端 105 项测试通过，生产构建成功。

## 最近完成

- 管理员首页升级为生产指挥中心看板，汇总生产、能耗、告警和报告数据，并增加近 7 天趋势、生产状态、快捷入口、Iconfont 风格双色图标、无障碍焦点状态与克制微动效。
- 告警中心按首页视觉标准重做横幅、五项概况卡、分级事件表、AI 洞察和实体报告区，并补齐筛选、持续时长、刷新反馈及窄屏布局。
- 文件派发页按首页视觉标准重做生产横幅、四步流程、三栏工作区、常驻派发确认和记录区，移除无信息增量的单项目子导航，原有参数复核、旧深链兼容与顺序派发流程保持不变。
- 领导报表按首页视觉标准重做查询横幅、四项指标、双趋势区和 AI 分析卡片；涨跌比例使用真实对比区间，保留自定义区间与近 12 个月数据隔离。
- 设备报表按首页视觉标准重做设备横幅内嵌查询栏、五项彩色指标、双能耗趋势和 AI 分析区；设备利用率改为可由真实匹配记录计算的能耗覆盖率，并保留区间查询与近 12 个月数据隔离。
- 车间报表按首页视觉标准重做生产横幅内嵌查询栏、五项彩色任务指标、紧凑任务表和 AI 分析区；沿用真实确认数据，并保留工人批量确认、本人撤销、管理员更正和审计流程。
- 领导、设备和车间三张标准报表统一为浅色表头、10px 面板圆角和紧凑行高；趋势图统一坐标网格与平滑折线，报表子导航与页面横幅保留 12px 间隔。
- 恢复领导和设备趋势表的固定高度区域滚动，长区间数据不再被页面样式裁切；车间任务表仍按页查看。
- 重做领导、车间和设备三类导出 HTML/PDF 的共享视觉模板，并统一导出图表主题、打印分页和 PDF 页码页脚。
- 三张标准报表的指标卡已改用真实数据迷你趋势图，并移除智能分析指标卡中的伪趋势线。
- 三张标准报表的查询区已抽成同一个 `StandardReportQuery` 组件，日期、图表类型、查询和导出的字体、颜色、尺寸与响应式布局不再由各页面重复定义。
- 三张标准报表的智能分析已统一收口到 `AnalysisPanel` 组件，共用分析结论、六项核心指标、2×2 多维分析和可追溯依据结构；色彩已对齐首页的白色卡面、浅蓝灰边界和语义色体系。
- 智能分析不再在字符串层截断长结论；多维分析卡保留紧凑默认高度，并为长文本提供逐卡展开、收起及键盘焦点状态。
- 整体 UI 色彩加深为工业蓝青体系：页面底色、卡片边界、表头、查询区和智能分析彩卡提高对比度，同时保留浅色数据阅读区。
- 首页、告警、文件派发和标准报表已统一页面标题、说明、模块标题、KPI、表格、控件与辅助信息字号；移除非必要的 Georgia 字体，图表文字补齐跨平台中文字体回退。
- 三张标准报表的头图标题区统一为英文眉题、中文标题、说明和数据信息四层固定轨道，页面切换时保持相同起点、字号和行高。
- 兼容旧车间日报的工人撤销和管理员更正，并增加分类常用原因。
- 文件派发页支持从 PDM 直接单选或跨页多选，批量建任务后顺序下载、校验、上传和指派；推送成功后回收临时实体副本。
- 标准文件名自动识别材质和板厚；非标准名必须手工补全参数并明确确认。
- 统一页面与 HTML 报表的中文日期格式和期间排序。
- 全局表格采用内容驱动自适应列宽。
- 智能分析增加服务端数据版本、SQLite 版本缓存、前端旧请求取消和同版本并发合并；报表数据就绪后立即开始分析，不再等待 4 秒。
- 车间报表翻页不再重置同一查询区间和数据版本的智能分析结果。
- 报表自动化页支持在线维护运行与 SMTP 参数，密码不回显，保存后重启生效。
- 文件派发在建任务时复核 PDM 版本和路径，历史物理记录不阻断重新派发。
- 修复缓存页面反复切换时隐藏查询、自动分析、图表、观察器和全局监听器继续运行的问题，并限制报表页面缓存数量。
- 补齐非缓存长期页面的串行轮询与请求取消：告警中心、工人车间页和报表生成页不再因慢请求或离开页面而叠加后台请求。
- 修复三张报表快速循环切换时 `KeepAlive max=2` 反复淘汰页面、ECharts 每次激活重建导致的主线程卡顿；三页改为固定有界缓存，图表仅在真正卸载时释放。
- 前端请求取消已延伸到 SQL Server：浏览器取消时按请求标识通知后端，后端对关联 pyodbc 游标执行 `cancel()`，不再只丢弃前端响应。
- 领导与设备报表的区间查询和近 12 个月趋势状态解耦，查询区间不再覆盖第二张趋势表。
- 领导与设备报表的 HTML/PDF 导出同步采用双周期数据，区间明细不再覆盖近 12 个月月度统计。
- 完成剩余页面的统一 UI 重构：报表生成、设置首页、数据库、报表设计、自动化和管理员管理共用生产场景页头、状态卡和紧凑面板规范；登录页升级为生产场景双栏入口，工人任务继续复用已重构的车间报表。
- 按 Web Interface Guidelines 完成可访问性与交互加固：补齐 Skip Link、实时状态播报、表单名称、弹窗键盘焦点、触屏/安全区样式、设计器可深链 Tab，以及数据库、设计器和自动化页面的未保存修改保护。
