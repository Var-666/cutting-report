# 项目进度

> 更新日期：2026-09-29。

## 当前状态

系统已进入持续完善和内网联调阶段。标准报表、区间查询/导出、智能分析、工人确认、切割文件派发、告警报告和报表自动化均已有可运行实现。报表智能分析直接使用大模型结果，模型失败时明确报错，不生成本地替代分析。当前后端 494 项、前端 124 项测试通过，生产构建成功。

## 最近完成

- 领导报表默认月份的四项指标自动与上一个自然月汇总比较，复用既有近 12 个月数据而不新增 SQL 查询；默认卡片明确显示“较上月”，自定义日期区间继续使用前一个等长区间并显示“较对比区间”。
- 告警大模型将单条 `limitations` 文本返回为字符串时，后端会确定性规范化为报告模板需要的字符串数组；提示词同步明确数组字段类型，其他无法安全解释的结构继续报错。失败报告释放关联事件，后续五分钟扫描会自动重试。
- `Cutter01` 告警监控固定从 `2026-09-29 00:00:00` 开始：SQL Server 查询按 `START_TIME` 过滤，起始口径首次生效时自动重置游标并补录当天数据，之后按固定高水位增量读取；起始日前本地旧事件不再进入列表、统计或新报告。告警事件表同时展示告警时间与系统发现时间，并增加每页 15 条的服务端分页；页签数量和 AI 汇总使用全量统计。
- 默认领导、车间和设备报表的智能分析定时检查改为只读 SQLite 的轻量版本接口，不再每 30 秒重建完整分析数据或访问 SQL Server；后台约每 5 分钟刷新生产数据并在模型调用前发布双表版本，模型失败不影响变更发现。自定义历史区间仍由查询或手动刷新驱动，避免影响原有报表口径。
- 三类标准报表的智能分析版本改为同时覆盖页面两张表：领导和设备分别校验主表与近 12 个月汇总表，车间两张派生表共用完整任务版本；任一表变化时返回 409，并通过专用恢复流程同步刷新两张表后再分析，普通区间查询仍保持与第二张汇总表独立。
- 三类标准报表的大模型输入由仅六项汇总事实扩展为“六项权威事实 + 页面两张完整数据表”；领导和设备分析沿用页面独立的近 12 个月区间，车间分析使用完整任务集而非当前分页，并裁掉内部标识和能管采样细节。提示词与缓存版本同步升级。
- 设备智能分析按气耗、电耗各自的覆盖情况描述 `partial` 来源：有记录时说明实际仪表数据及覆盖范围，全缺失时说明无有效记录，不再写成“来源未知”；分析缓存版本升级，旧文案重新生成。
- 统一设备报表的单日与区间查询改用同一任务能耗计算路径，保留区间日汇总；同一天两种查询方式的任务数值、设备范围、插值状态和分析源版本已加回归测试并保持一致。
- 设备报表智能分析提示词不再要求模型先按“实测、模拟、不可用”分类，改为说明已记录能耗、任务覆盖范围与基于仪表读数的计算方式；插值不等同模拟，也不把已记录数值笼统降为“只能参考”。提示词版本更新，旧分析缓存不再命中；后端回归测试通过。
- 文件派发双栏桌面布局设 600px 初始最小高度，由右侧文件区决定后续行高，左侧目录等高并独立滚动；同时收紧左栏 Grid 最小列宽和项目选择行，避免数量文字、下拉框与“打开”按钮越界裁切。窄屏单列取消桌面最小高度，保留有界目录滚动。
- 智能分析的核心指标卡改为短标题和复合值首段概览，完整值与来源仍可在下方查看；不改变六项事实、模型输入或统计口径。
- 领导、车间和设备报表的模型提示词按六项事实重新明确四段分工、场景重点、缺失数据处理和可执行建议；每段通常用两句说清判断与依据或影响，不为凑字编造。保留直接使用模型结果的流程，不恢复内容硬校验。提示词版本更新使旧分析缓存失效。
- 报表自动化启停、扫描间隔、邮件重试与 SMTP 参数保存后即时发布给同一运行时快照；新任务与邮件无需重启服务，运行中邮件保持原配置，数据库配置仍需重启。
- 批量文件派发补齐同文档多版本选择拦截、服务端标准名和参数确认、逐项任务编号/结果、失败项状态核对与安全重试；上传结果未知不会自动重传。
- 智能分析的模型输入保持场景、周期和六项事实；报表分析直接使用模型生成的四段内容，不再执行引用、数值和语义硬校验或二次修正。提示词版本升级使既有分析缓存失效并重新生成。
- 领导、车间、设备和告警智能分析均只接受大模型结果；旧统计分析入口、本地规则降级器和带提示完成状态已删除。
- 页面报表版本随分析请求提交；只有模型未返回页面所需的四段文本时才报错，不再因内容判断拒绝模型结果。
- 领导、车间和设备报表统一加载、空数据、失败与重试状态；已有数据刷新时保留图表和表格，初次加载指标使用 `--`，不再提前显示虚假的零值。

## 当前问题

- 需在实际内网环境验证 SMTP 参数、定时生成、附件和失败重试全链路。
- 需在实际 PDM/FO/魔盒环境对批量推送、重复任务和推送后本地清理做验收。
