# 项目进度

> 更新日期：2026-10-24。历史过程与当时验证结果见 [变更记录](changelog.md)。

## 当前状态

系统处于内网联调阶段，支持 Cutter01（20KW）与 Cutter02（30KW）按设备隔离的报表、确认、告警及缓存。生产数据源为 SQL Server，Web 与 Worker 独立运行；真实双设备数据及外部服务仍待现场验收。

## 最近完成

- 分离 Session 查询与高成本鉴权，保留 HR 安全复核和8并发保护，修复取消后的容量释放。
- 增加管理员只读配置诊断，显示来源、保存目标及 Web/Worker 各自生效状态。
- 完成多设备访问隔离和双进程协调，精简管理页面，统一文件选择与派发流程。

实现约定见 [系统架构](architecture.md)，验证证据及对应提交见 [变更记录](changelog.md)。

## 当前问题

- 多设备升级前需核实2026-08-19、2026-08-23两份空日报的归属；迁移会拒绝歧义数据，不能猜测或删除。见 [迁移说明](multi-device-isolation.md)。
- Cutter02 尚未绑定能耗仪表；真实生产任务、告警映射、HR、PDM/FO、魔盒、SMTP及模型异常/负载仍需内网验收。
- 模型并发10、响应180秒及重试策略的生产效果待更新部署后观察；本地测试结果不能代替现场验证。
