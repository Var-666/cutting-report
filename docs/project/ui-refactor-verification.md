- 后端、API/生成类型、统计公式、数据库访问、权限和生产配置未改动。没有新增依赖、Store、Event Bus 或通用状态框架。

## 本轮补查发现并修复

- 车间页管理员仅编辑日期就清空结果，且分页、导出、AI 刷新读取草稿。现保留已应用结果，相关操作固定使用已应用范围；跨日重新进入默认页仍清空旧日数据，工人日期/确认流程保持原语义。
- 月度能耗后台读取异常原先被吞掉；现显示局部警告，保留汇总、取消/代际保护及原重试上限。
- 切割首页部分请求失败后缺少重试入口；现可重新读取，成功后错误消失。
- 设备选择器的非搜索 Naive 控件没有实际 combobox 名称；复用既有 AppSelect 后，设备和跨产线切换在真实焦点控件上可定位。
- 车间 Top 5 图窄面板数值刻度重叠；减少刻度并启用重叠隐藏，不改图表类型或数据。
