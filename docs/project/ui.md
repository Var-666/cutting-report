# 前端与 UI 约定

> 更新日期：2026-09-15。

## 通用规范

- 页面使用 Vue 3 Composition API；管理员、工人和功能分组分别由 `layouts/` 管理。
- 统计报表的页面查询、导出和智能分析使用同一已应用区间，不在子组件中重新推导日期。
- 中文日期由 `frontend/src/utils/dateDisplay.js` 统一格式化：月份、日期、日期时间不应在页面内各自拼接。
- 时间区间的原始值保留 ISO/`YYYY-MM-DD` 形式用于 API 和排序；格式化仅用于显示。

## 表格

- 应用内页面表格统一添加 `v-content-table`，对应指令位于 `frontend/src/directives/contentTable.js`。
- 列宽先根据当前表头和渲染行计算内在宽度，再将容器剩余宽度平均分配给各列。列宽通过生成的 `colgroup` 同步到表头、正文和汇总行。
- 表头和单元格默认居中、单行显示；超出宽度时使用省略。窄屏溢出只在表格容器内横向滚动。
- 列宽指令通过容器尺寸观察器重算；新增页面不要手工维护第二套百分比列宽。

## 页面交互

### 车间确认

- 更正原因弹窗根据工人撤销、管理员撤销和管理员改派显示对应的常用原因。
- 常用原因是快捷填写，用户仍可输入其他原因；选中项需有清晰激活态。

### 文件派发

- 文件派发使用一套 PDM 项目/目录树和文件表格，不要求先将文件手工保存到系统。
- 来源文件表支持单文件派发、当前页全选和跨页多选，最多 20 个文件；每个文件保存独立参数，不共用一份可变表单状态。
- 标准文件名自动填入材质和厚度；非标准文件不猜测参数，必须手工填写并勾选人工核对确认。
- 执行前以弹窗列出选中任务及其参数；系统逐项复核版本和路径，再顺序下载、校验、上传和指派。
- 执行后分别显示成功、失败、重复和本地清理警告；旧下载、推送深链统一跳转到文件派发页。

### 智能分析

- `AnalysisPanel` 接收服务端 `dataVersion`，数据变化后等待 4 秒稳定再自动请求，避免同一页连续加载造成重复分析。
- 等待、分析中、错误、降级分析、已缓存和手动重新分析状态要分开呈现。

### 报表自动化

- 页面依次分为“运行与邮件参数、新建/编辑任务、定时任务、发送记录”。
- SMTP 密码不回显；已配置时使用“留空则保留原密码”占位提示。
- STARTTLS 与 SSL/TLS 互斥；保存成功后必须明确显示“需重启生效”。
- 配置加载失败时不显示可提交的默认表单，仅显示错误和重试入口，防止覆盖有效配置。
