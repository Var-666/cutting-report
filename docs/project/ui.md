# 前端与 UI 约定

> 更新日期：2026-09-24。

## 通用规范

- 页面使用 Vue 3 Composition API；管理员、工人和功能分组分别由 `layouts/` 管理。
- 项目品牌标识统一使用 `frontend/src/assets/project-logo.png`；管理员导航、工人导航、登录页和浏览器图标共用同一透明资产，并由 Vite 输出到生产环境可托管的 `/assets` 指纹路径，不再使用根路径静态文件或 CSS 临时绘制的三柱标识。
- 通用线性图标使用 `frontend/src/components/AppIcon.vue`，造型参考阿里巴巴 Iconfont 官方图标库，并以本地 SVG 双色渐变呈现；图标按业务语义使用蓝、青、绿、橙、红、紫色系，不依赖在线 CDN，也不使用易受系统字体影响的 Unicode 图形。
- 管理员首页采用“指挥中心横幅、六项核心指标、趋势/状态/告警、报告/入口/洞察”的紧凑看板结构；各管理员页面共用首页的浅灰蓝背景与 1520px 最大内容宽度，窄屏统一留 12px 侧边距；首页局部保留工业蓝青色板和 12px 白色卡片。各模块独立加载，生产、能耗、告警和报告均显示真实接口数据，窄屏按模块逐级折行。管理员顶栏的高度、Logo、导航和账户尺寸全站共用，切页时不再跳变。
- 管理员和工人内容区统一在顶栏下留 16px；首页和报表子导航不再额外叠加顶距。横幅、流程卡及后续面板保留各页面现有的 12–16px 模块间距，卡片不贴顶栏。
- 首页快速入口保留三张横向业务小卡片，每张卡片显示图标、报表名称、一句业务说明和方向箭头；只在首页维护该样式，不覆盖其他页面的快捷入口。
- 告警中心沿用首页的蓝青主色、彩色语义图标、圆角卡片和字号层级；概况指标只展示接口可验证的数据，告警事件同时展示生产库告警时间和系统发现时间，并支持按严重、一般、提示筛选；桌面端为事件表与洞察侧栏，窄屏按内容顺序折行。
- 领导报表沿用首页生产横幅、彩色指标卡和蓝青色内容层级；指标涨跌只使用接口返回的 `comparison_total`，没有对比数据时明确显示“暂无对比”。区间明细与近 12 个月趋势继续维护独立数据状态。
- 设备报表采用“设备横幅内嵌查询栏、五项设备指标、区间能耗、近 12 个月能耗、智能分析”的单页结构；指标仅使用接口真实数据，其中能耗覆盖率按电耗/气耗匹配记录计算，不用缺失字段模拟设备利用率。
- 车间报表采用“生产横幅内嵌查询栏、五项任务指标、任务结构概览、任务筛选表、工人工时汇总、智能分析”的单页结构；概况卡仅展示任务总数、待确认、已确认、涉及工程和确认率，不用缺失字段模拟异常任务或环比。
- 首页字体按桌面可读性分为标题、核心数值、模块标题、正文和辅助信息五级；窄屏不缩小正文来强行容纳导航，而是保留图标并隐藏重复文字标签。
- 全局字号使用统一语义标尺：页面主标题 38px（移动端 31px）、页面说明 12px、模块标题 14px、KPI 名称 11px、KPI 数值 22px、表头 10px、表格正文 11px、控件 11px、辅助信息不小于 9px。除 SQL、文件名和时间数值外不使用等宽字体，不使用 Georgia 等额外装饰字体。
- 首页交互参考 shadcn-vue、Radix Vue、PrimeVue/Sakai 的卡片层级和可访问交互：导航、卡片链接和快捷入口必须提供清晰的悬停、按下及键盘焦点状态；首页仅保留轻量悬停与加载反馈，并响应 `prefers-reduced-motion`。
- 动效仅用于表达层级、状态和操作反馈，不在生产看板使用大幅视差、3D 倾斜或持续干扰读数的装饰动画。
- 报表生成、设置首页、数据库、报表设计、自动化和管理员管理统一使用 `ManagementPageHero` 与 `management-page` 密度系统：生产场景头图承载页面识别和实时状态，工作面板统一 10px 圆角、浅蓝灰表头、紧凑控件与无斑马纹数据行。工人任务页直接复用车间报表结构，不维护重复样式。
- 登录页使用同一生产场景图、工业蓝青色板和彩色业务图标，以“生产能力说明 + 白色认证面板”双栏呈现；认证、初始化和 HR 登录逻辑不因视觉重构改变。
- UI 可访问性遵循 Web Interface Guidelines：管理员与工人布局提供 Skip Link；异步成功/失败使用 `status`/`alert` 播报；关键弹窗统一使用焦点循环、Escape 关闭和关闭后返回焦点；表单控件提供稳定 `name`、自动填充语义及可访问标签；数据库、报表设计和自动化编辑页离开前提示未保存修改。
- 报表设计器的查询、定义和模板 Tab 使用完整 ARIA Tab 语义，支持左右方向键、Home/End，并将当前 Tab 写入 URL 查询参数以支持刷新和深链恢复。
- 统计报表的页面查询、导出和智能分析使用同一已应用区间，不在子组件中重新推导日期。
- 领导、设备报表的近 12 个月趋势使用独立数据状态；区间查询只更新区间明细、汇总和智能分析，不覆盖第二张近 12 个月图表及表格。
- 领导、设备报表导出 HTML/PDF 时同样保持双周期：第一组明细及智能分析使用已应用查询区间，第二组趋势始终使用页面独立维护的近 12 个月周期，禁止用区间聚合覆盖月度汇总。
- 标准报表页子导航与首个内容横幅之间保留 12px 间距；报表面板统一使用 10px 圆角和紧凑密度。
- 领导、设备和车间报表的查询区统一使用头图右下角内嵌的 `StandardReportQuery` 组件；日期、图表类型、查询和导出的字号、控件高度、间距、颜色及响应式布局只在组件内维护，页面仅传入状态和事件。
- 三张标准报表的智能分析统一使用 `AnalysisPanel` 组件，并固定为“分析结论、六项核心指标、2×2 多维分析、模型输入数据”结构；组件复用首页的白色卡面、浅蓝灰边界及蓝、青、红、绿语义色，页面不再传入独立样式类或覆盖网格列数。
- 三张标准报表的头图信息区统一使用 `report-hero-copy` 四层轨道：英文眉题、38px 中文标题、两行说明和 20px 数据信息栏；即使某项暂未显示也保留轨道高度，避免页面切换时文字上下跳动。
- 领导、设备报表的图表共用蓝、青、橙色板、坐标网格和平滑折线；车间报表在明细表之前展示完整筛选结果的任务时长环图、确认状态比例条与切割长度 Top 5 横向条形图，图表不受当前分页影响，任务与工人明细仍保留表格。Top 5 只纳入有效正长度，缺失数据明确显示空状态。
- 领导和设备报表的固定高度趋势表允许在表格区域内纵向滚动；车间任务表继续使用分页，不增加固定高度内滚动。
- 三张标准报表的导出 HTML/PDF 共用“生产档案蓝图”视觉：深海军蓝报告识别带、连续指标带、浅蓝表头、无斑马纹数据表和四色智能分析区；PDF 使用 A4 横向、重复表头、长表分页及系统名/页码页脚。
- 三张标准报表的指标卡统一使用 `MetricSparkline`：领导卡读取每日汇总，车间卡读取后端按日聚合，设备卡读取任务和能耗记录；无有效数据时明确显示暂无趋势，禁止固定 SVG 装饰折线。
- 中文日期由 `frontend/src/utils/dateDisplay.js` 统一格式化：月份、日期、日期时间不应在页面内各自拼接。
- 时间区间的原始值保留 ISO/`YYYY-MM-DD` 形式用于 API 和排序；格式化仅用于显示。

## 表格

- 应用内页面表格统一添加 `v-content-table`，对应指令位于 `frontend/src/directives/contentTable.js`。
- 列宽先根据当前表头和渲染行计算内在宽度，再将容器剩余宽度平均分配给各列。列宽通过生成的 `colgroup` 同步到表头、正文和汇总行。
- 表头和单元格默认居中、单行显示；超出宽度时使用省略。窄屏溢出只在表格容器内横向滚动。
- 领导、设备和车间三张标准报表统一使用中浅蓝灰表头（`#d8e7ee`）和深蓝灰文字（`#2f536b`），不在页面之间混用深色表头。
- 列宽指令通过容器尺寸观察器重算；新增页面不要手工维护第二套百分比列宽。

## 页面交互

### 车间确认

- 更正原因弹窗根据工人撤销、管理员撤销和管理员改派显示对应的常用原因。
- 常用原因是快捷填写，用户仍可输入其他原因；选中项需有清晰激活态。

### 文件派发

- 文件派发使用一套 PDM 项目/目录树和文件表格，不要求先将文件手工保存到系统。
- 页面沿用首页的生产横幅、彩色语义图标、圆角卡片和蓝青主色。桌面工作区首行为“固定目录栏 + 自适应文件区”，派发确认作为下一行横向摘要，避免十列表格、目录树和确认栏互相挤压；文件区有 600px 初始最小高度并决定首行高度，目录栏等高且目录树仅在栏内滚动，窄屏折为单列并取消桌面最小高度。四步流程状态随选择、确认和派发结果变化。
- 文件派发只有一个正式页面，不显示单项目子导航；管理员主导航直接进入派发工作区，旧下载、推送深链仍重定向到该页面。
- 来源文件表支持单文件派发、当前页全选和跨页多选，最多 20 个文件；每个文件保存独立参数，不共用一份可变表单状态。
- 标准文件名自动填入材质和厚度；非标准文件不猜测参数，必须手工填写并勾选人工核对确认。
- 同一 PDM 文档一次只能选择一个版本；标准名对应的材质或板厚被人工修改时也必须再次确认。
- 执行前以弹窗列出选中任务及其参数；系统逐项复核版本和路径，再顺序下载、校验、上传和指派。
- 执行后逐项显示成功、失败、重复、任务编号和本地清理警告；失败项可在弹窗核对状态、重试创建或安全重试，PDM 版本/路径过期需刷新清单重选。上传结果未知时不提供盲目重传。

### 智能分析

- `AnalysisPanel` 接收服务端 `dataVersion`，报表数据就绪或版本变化后立即请求分析；切换查询条件时取消旧请求，后端继续按完整数据版本复用缓存并合并同版本请求。
- 等待、分析中、错误、已缓存和手动重新分析状态要分开呈现；页面只展示大模型分析结果，模型失败时显示错误和重试入口。
- 智能分析继续内嵌在领导、设备和车间报表中，不单独建立分析路由；首页洞察入口进入对应报表。
- 智能分析的核心指标卡只展示复合事实值的首段概览，完整事实值和来源保留在下方“模型输入数据”；结论和分析卡片默认展示完整文字，允许随内容增高和长词换行，不截断正文。
- 智能分析的页面、缓存和导出共用服务端展示用语：将“未标注工程”等内部分类名说明为“工程号未填写”，将“高位生产日”“环比/同比”等改成日常说法；只调整结果文案，不改变原始任务归类和计算。页面展示模型输入数据，不宣称逐句核验模型结论。

### 报表自动化

- 页面依次分为“运行与邮件参数、新建/编辑任务、定时任务、发送记录”。
- SMTP 密码不回显；已配置时使用“留空则保留原密码”占位提示。
- STARTTLS 与 SSL/TLS 互斥；保存成功后必须明确显示“即时生效”，正在执行的邮件按旧配置完成。
- 配置加载失败时不显示可提交的默认表单，仅显示错误和重试入口，防止覆盖有效配置。
