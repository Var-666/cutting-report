# 数据库设计说明 V2（注释版）

## 1. 文档说明

- 来源：《数据库设计说明V2.pdf》。
- 整理目的：在原始表结构基础上补充表中文名称、业务说明、字段中文名称和字段含义，便于开发、测试、运维和报表口径核对。
- 原文未提供字段是否允许为空、默认值、索引、外键约束以及大多数业务计量单位，因此本文对应位置统一标记为“未说明”，不作推测。
- “长度/精度”列表示数据库字段长度或数值精度，不代表毫米、米等业务单位。
- 原文将 `task.OP_LENGTH_GROOVE` 说明写为“破口长度”。结合字段名、`GROOVE_TYPE` 和 `task_groove` 表定义，本文统一规范为“坡口长度”。
- 原文中的配置示例包含 Token、Secret 和密码。本文只保留配置项名称与用途，不复制任何配置值。

## 4. 表关系与数据流说明

### 4.1 明确的业务关联

| 主表 | 从表 | 关联字段 | 关系说明 |
| --- | --- | --- | --- |
| `task` | `task_groove` | `task.TASK_ID = task_groove.TASK_ID` | 一个切割任务可以对应多条按坡口类型拆分的长度统计记录。 |
| `task` | `task_part` | `task.TASK_ID = task_part.TASK_ID` | 一个切割任务可以对应多条零件明细记录。 |

说明：以上关系来自字段说明中的“关联 `task.task_id`”，原文未明确数据库中是否实际创建外键约束。

### 4.2 业务数据分类

| 数据类别 | 相关表 | 用途 |
| --- | --- | --- |
| 生产任务 | `current_task`、`task`、`task_groove`、`task_part` | 实时任务展示、历史任务统计、坡口长度拆分和零件明细。 |
| 设备状态 | `laser_cutter_status`、`roller_status`、`roller_his` | 展示切割机与辊床实时状态，追溯辊床状态变化。 |
| 告警 | `alarm_info`、`roller_alarm_dic` | 保存设备告警并将辊床报警编码转换为文字描述。 |
| 能耗与电参 | `electric_current`、`power_record` | 保存实时电参和历史能耗；两表均被原文标注为未使用。 |
| 系统配置 | `sys_config` | 保存设备地址、通信凭据和同步参数。 |
